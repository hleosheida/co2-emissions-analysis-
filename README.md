# CO2 Emissions Analysis

An exploratory analysis of global CO2 emissions by country, built with Python in Google Colab.

## Data
Public dataset from [Our World in Data](https://github.com/owid/co2-data), covering CO2 emissions by country and year.

## Tools
Python, pandas, matplotlib

## What I did
- Loaded and explored the dataset
- Compared CO2 emissions per person for Sweden, Germany, India, and the United States over time
- Ranked the top 10 total CO2 emitters in 2022
